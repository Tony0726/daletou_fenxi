# 🎯 大乐透历史分析

大乐透（超级大乐透）历史开奖数据的走势分析网页。无需安装、无需构建，打开即用，同时支持移动端横竖屏与桌面端浏览。

> 本仓库另有 PyQt5 桌面版参考实现 `daletou5.py`（未纳入版本控制），网页版的分析逻辑与其逐列对应。

## ✨ 功能特性

- **三张分析表**：以 Tab 切换，逐期展示不同维度的分析指标
- **多数据源容错**：优先拉取体彩官方接口，失败自动回退 GitHub 镜像，再失败使用内置离线数据，离线也能用
- **可选期数**：支持 10 ~ 200 期（默认 30 期）
- **遗漏统计**：表尾 4 行汇总「总出现次数 / 平均遗漏值 / 最大遗漏值 / 最大连出值」
- **导出 Excel**：一键导出当前表格为 `.xlsx`（基于 SheetJS）
- **响应式布局**：适配手机竖屏 / 横屏 / 小平板，期号列吸左固定、表头吸顶、内部横竖滚动
- **可视化配色**：红球、蓝球、遗漏值、下期命中标色显示

## 📊 三张分析表

| 表格 | 主要分析维度 |
| --- | --- |
| **第一张表** | 前区 5 位号码按位统计：五行（金木水火土）、奇偶、大小、号码分布 |
| **第二张表** | 后区蓝球分析：跨度、升降平、和值、和尾、五行、奇偶、大小、分区（0-3） |
| **第三张表** | 综合派生值：和值、前后一/前二、合值、尾数大小、相邻期差值、重复号码等 |

每张表的表尾 4 行均为「总出现次数 / 平均遗漏值 / 最大遗漏值 / 最大连出值」汇总。

## 🚀 快速开始

### 本地使用

直接用浏览器打开 `index.html` 即可，无需任何构建或服务端。

页面加载后会自动获取数据；也可手动操作：

1. **获取最新数据** —— 从体彩官方接口拉取最新约 300 期开奖数据
2. **选择期数**（下拉框，10~200）—— 分析最近 N 期走势
3. **刷新** —— 按当前期数重新生成表格
4. 在「第一张表 / 第二张表 / 第三张表」Tab 间切换查看

### 在线访问

项目已部署至 Cloudflare Pages：<https://daletou-fenxi.pages.dev>

## 🔧 数据来源

数据按以下顺序自动降级获取，保证任何网络环境下都能出表：

1. **体彩官方接口**：`webapi.sporttery.cn` 历史开奖查询（分页并行拉取约 300 期）
2. **GitHub 镜像仓库**：`yangxb919/lottery-data`（jsDelivr CDN / GitHub raw）
3. **内置离线数据**：随页面打包的近 30 期数据（来源：体彩官方）

> ⚠️ 本项目仅作历史数据统计展示，不提供任何投注建议。彩票开奖具有随机性，请理性购彩。

## 📦 部署

推送 `main` 分支即触发 GitHub Actions（`.github/workflows/cloudflare-pages.yml`）自动部署到 Cloudflare Pages。

- Pages 项目名：`daletou-fenxi`
- 需在仓库 Secrets 中配置 `CLOUDFLARE_API_TOKEN`
